👛 Smart Wallet Tracker (PWA)
A privacy-focused, offline-first Progressive Web App designed for seamless personal expense tracking and financial analytics.
📌 Overview
Smart Wallet Tracker is a lightweight, responsive Progressive Web App built to solve day-to-day expense management challenges without compromising user privacy. The application operates entirely on client-side architecture, ensuring fast load times and uninterrupted functionality even in zero-connectivity environments.
✨ Key Features
📶 Offline-First Architecture: Service Workers handle background caching and offline runtime operations.
📱 PWA Installable: Standalone native app experience across Android, iOS, Desktop, and ChromeOS.
🔒 Data Privacy & Security: All financial records remain localized on the device using client-side storage mechanisms.
📊 Smart Expense Analytics: Real-time summary of incomes, expenditures, and net balance calculations.
⚡ Zero External Dependencies: Pure native Web APIs ensure minimal overhead, lightning-fast boot times, and high runtime performance.
🛠️ Tech Stack & Architecture
Frontend: HTML5, Modern CSS3 (CSS Grid/Flexbox), ES6+ JavaScript
PWA Capabilities: Web App Manifest (manifest.json), Service Worker (sw.js)
Storage Layer: LocalStorage / IndexedDB
Version Control: Git & GitHub Workflow
🚀 Getting Started
Prerequisites
To run or develop this application locally, you only need a modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Brave).
Installation & Local Setup
Clone the Repository:
git clone https://github.com/roopfatima/Smart_Wallet_Tracker_App.git


Navigate into the Directory:
cd Smart_Wallet_Tracker_App


Launch the App:
Open index.html directly in your browser, or launch it using VS Code's Live Server extension.
